# Total Care FM demonstration

Website demonstration by Wizerd, retaining the original aperture logo and blue identity.

## Local preview

Run `python3 -m http.server 58737 --bind 127.0.0.1` from this directory, then open the local address in a browser.

The site is plain HTML, CSS and JavaScript. It has no build step or external runtime dependencies. All image and font assets are local. Directional icons use SVG so they cannot become coloured emoji on a phone.

## Demo behavior

Mobile navigation, service panels, changing photography, environment tabs, scroll effects and an enquiry preview are implemented. The enquiry preview sends or stores nothing. Copy and photography illustrate a design direction, not verified projects, client relationships or service credentials.

See STOCK-SOURCES.md for photography credits and the licence texts in assets for fonts. The original architectural image sources are recorded in ASSET-CREDITS.md.

## Hosting

GitHub Pages serves the root of the codex/total-care-demo branch. The demo can be opened without a login. It is marked noindex, and robots.txt requests that crawlers do not index it.
